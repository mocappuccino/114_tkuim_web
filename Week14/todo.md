# 專案待辦事項：HoYoLAB 風格網頁

本專案旨在如果不使用框架 (Vanilla JS/CSS/HTML)，仿照 HoYoLAB 的版面風格建立一個響應式的網頁。

## 核心版面結構 (Layout Structure)
- [ ] **固定導覽列 (Sticky Header)**
    - 左側：Logo 區域
    - 中間/右側：搜尋欄
    - 右側：使用者頭像/功能圖示
- [ ] **主要版面 (Main Layout)**
    - **左側邊欄 (Left Sidebar)**：導覽選單 (圖示 + 文字)。
    - **中間動態牆 (Center Feed)**：貼文卡片捲動區。
    - **右側邊欄 (Right Sidebar)**：熱門話題 / 推薦工具 (或是簡單的資訊卡片)。

## 元件 (Components)
- [ ] **貼文卡片 (Post Card)**
    - 發表者資訊：頭像、使用者名稱、時間。
    - 內容區：標題、文字預覽。
    - 媒體區：縮圖 (如果有圖片)。
    - 底部資訊：按讚數、留言數、瀏覽數。
- [ ] **左側導覽選單 (Navigation Menu)**
    - 目前頁面高亮樣式 (Active state)。
    - 滑鼠懸停效果 (Hover effects)。
- [ ] **右側資訊卡 (Info Card)**
    - 簡單的列表項目 (例如：熱門話題)。

## 技術限制 (Technical Constraints)
- 純粹使用 **HTML5**, **CSS3**, **ES6+ JavaScript**。
- 不使用任何外部框架 (No Frameworks)。
